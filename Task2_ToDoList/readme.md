# To-Do List

## Overview

The To-Do List is a Python application that helps users organize daily tasks. It allows users to add, view, mark as completed, and delete tasks while storing data locally using a JSON file.

## Objective

The objective of this project is to build a simple task management application that demonstrates file handling and basic CRUD operations using Python.

## Features

- Add new tasks
- View all tasks
- Mark tasks as completed
- Delete tasks
- Local JSON data storage
- Simple command-line interface
- Input validation

## Technologies Used

- Python
- JSON
- OS Module

## Installation

No external dependencies are required.

## Usage

Run the application:

```bash
python ToDoListApp.py
