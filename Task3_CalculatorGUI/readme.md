# Calculator

## Overview

The Calculator is a Python-based desktop application built using Tkinter. It provides a simple and user-friendly interface for performing basic arithmetic calculations, including addition, subtraction, multiplication, and division.

## Objective

The objective of this project is to develop a GUI-based calculator that demonstrates Python fundamentals, event handling, and graphical user interface development.

## Features

- User-friendly graphical interface
- Basic arithmetic operations
- Parentheses support
- Decimal calculations
- Backspace functionality
- Clear screen option
- Handles invalid expressions
- Division by zero validation

## Technologies Used

- Python
- Tkinter

## Installation

No external dependencies are required.

## Usage

Run the application:

```bash
python CalculatorGUI.py
