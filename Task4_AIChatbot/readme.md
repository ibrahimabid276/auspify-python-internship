# AI Chatbot

## Overview

The AI Chatbot is a rule-based conversational application developed in Python. It can respond to greetings, answer simple questions, perform basic mathematical calculations, and maintain conversation history using intent matching techniques.

## Objective

The objective of this project is to develop a simple AI-powered chatbot that demonstrates natural language processing concepts, intent recognition, and conversational logic using Python.

## Features

- Rule-based conversation system
- Intent recognition
- Greeting and farewell responses
- Basic question answering
- Mathematical calculations
- Conversation history
- Fuzzy text matching
- Fallback responses

## Technologies Used

- Python
- Regular Expressions (re)
- random
- difflib

## Installation

No external dependencies are required.

## Usage

Run the application:

```bash
python AI chatbot.py
